# PaceLeague mobile app packet

Open **PACELEAGUE_APP_PACKET.md** for the complete brief. This is an original Runify-inspired product plan and visual concept, not an implemented mobile app.

- `designs/`: three PNG boards covering nine screens.
- `specs/`: product, requirements, technical, design, evaluation, decision, business and build-plan documents.
- `design-tokens.json` and `sample-fixtures.json`: exact implementation inputs; fictional data.
- `SOURCES.md`, `IMAGE_PROMPTS.md`, `SKILL_COVERAGE.md` and `VALIDATION.md`: provenance and limitations.
- `specs/EVIDENCE_LEDGER.csv`: claim-level evidence.

Extract the whole ZIP to keep relative image/document references together. Start development with F01 in PLAN.md: the physical-device GPS and recovery milestone. Written requirements and tokens take precedence over raster approximations. Name, price, budget, audience and platform sequence remain explicit planning assumptions.
